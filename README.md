# 拾光写真 — 暗夜影像志

纯静态成人艺术写真展示站，无构建步骤、依赖或后端。

## 部署到 Cloudflare Pages

将此文件夹连接到 Cloudflare Pages 的 Git 部署，Framework preset 选 **None**，Build command 留空，Build output directory 填 `/`（仓库根目录）。也可直接上传本目录文件。
